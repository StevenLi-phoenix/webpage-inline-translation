## 安装

### Microsoft Edge

1. 打开 [WuPage Translator 商店页面](https://microsoftedge.microsoft.com/addons/detail/wupage-translator/ophhojnppohaklhcdaheplkodopmplfg)。
2. 点击「获取」，按提示完成安装。
3. 在浏览器扩展菜单中，将 WuPage 固定到工具栏。

### 手动安装（Chrome / Edge）

1. 从 [Releases](https://github.com/mr-wuliu/wupage/releases/latest) 下载对应浏览器的安装包：Chrome 使用 `wupage-<version>-chrome.zip`，Edge 使用 `wupage-<version>-edge.zip`。
2. 解压发布包，保留解压目录。
3. 打开扩展管理页：Chrome 使用 `chrome://extensions`，Edge 使用 `edge://extensions`。
4. 开启「开发人员模式」，点击「加载已解压的扩展程序」或「加载解压缩的扩展」。
5. 选择包含 `manifest.json` 的解压目录。

Chrome 与 Edge 安装包使用相同的 Chromium 构建；较早版本仅提供的 `edge.zip` 也可用于 Chrome。手动更新时，将新版文件解压到原安装目录并替换旧文件，然后在扩展管理页重新加载扩展。

安装或更新后，刷新已打开的网页。

### Firefox（测试版）

需要 Firefox 154 或更新版本，使用独立的 Firefox 构建。当前尚未提供商店安装或 Mozilla 签名包。

1. 按照[开发指南](docs/development.md#firefox-构建与验证)生成 `dist-firefox/`，或解压 Firefox 测试包。
2. 打开 `about:debugging#/runtime/this-firefox`，点击「临时载入附加组件」。
3. 选择 `dist-firefox/manifest.json`，或解压目录中的 `manifest.json`。
4. 刷新需要翻译的网页。

临时加载的扩展会在退出 Firefox 后移除，下次启动需重新加载。Edge / Chrome 安装包不能用于 Firefox。

## 视频字幕（实验）

源码构建已包含视频字幕实验功能。与商店版同时安装时，可使用「WuPage 视频字幕预览版」区分；重新加载扩展后，需要刷新视频页。

1. 在 WuPage 扩展弹窗的功能开关区开启「视频字幕」（默认开启），再将鼠标移入视频播放器，点击右上角「字幕翻译」开始翻译。
2. 播放器下部显示双语字幕，暂停、倍速和拖动进度时自动同步。没有字幕时，先在视频播放器开启 CC / 字幕；部分网站的字幕需要登录。
3. 点击字幕入口旁的齿轮，可直接选择目标语言、翻译服务、原字幕语言和字号，或关闭原文。设置立即生效；关闭设置不会停止翻译。
4. 再次点击「双语已开」停止翻译，恢复原生字幕。字幕控制会在不操作时收起，鼠标移入播放器或使用键盘聚焦时重新显示。

「在此网站自动开启」默认关闭，勾选后会在该网站的主要视频中自动启用。播放列表或单页换视频会重新读取字幕，旧视频的迟到译文不会覆盖新视频。目标语言或服务变化会自动重新开始，字号、背景与原文显示变化复用现有译文。

弹窗中的「视频字幕」开关对所有网页生效。关闭后会停止字幕翻译、恢复网站原字幕并隐藏播放器入口；重新开启后恢复入口，已保存的字号、字幕语言和网站自动开启偏好会保留。

内置 YouTube、Bilibili、Netflix、Vimeo、Disney+、Prime Video、TED、Coursera 和 Udemy 的播放器适配，并支持通用 HTML5 字幕轨。优先读取带时间轴的完整字幕；无法取得完整字幕时，翻译播放器当前显示的文字字幕。网站必须有可用字幕；登录限制、字幕授权、网站改版或图片字幕可能影响可用性，具体实机与样本验证范围见[开发指南](docs/development.md#视频字幕实验)。YouTube 在需要时自动开启原生字幕，停止后还原；其他网站可先通过播放器选择所需的原字幕。

字幕翻译复用当前文本翻译服务，不识别视频语音、不读取麦克风，也不上传视频或音频。完整字幕会提前翻译当前及未来约 15 秒的文本，即使视频暂停也会准备附近字幕；在线服务消耗对应文本额度。字幕译文只在有上限的会话缓存中复用，不写入持久翻译缓存。停止和跳转会取消旧任务；已经到达服务商的请求仍可能被处理或计费。

「更多选项」提供字幕背景、时间偏移及 SRT / WebVTT 导入。文件必须使用 UTF-8 编码，上限为 2 MiB、20,000 条字幕，每条最多 4,000 字符；文件仅在当前页面内存中读取，刷新网页或换视频后清除。播放器容器全屏沿用双语覆盖层，视频元素原生全屏使用临时双语字幕轨；跨域内嵌播放器可在其内部使用同样的入口。浏览器画中画窗口不显示网页覆盖层，需回到原播放器查看字幕。暂不提供无字幕听译或配音。

## 网页翻译

### 全文翻译

1. 打开网页，点击工具栏中的 WuPage 图标。
2. 设置源语言、目标语言和翻译服务。
3. 点击「翻译全文」，在当前页面查看译文。
4. 点击「显示全文」，恢复原文。

初始配置为自动检测源语言、翻译为简体中文，使用 Google 翻译，也可切换到 OpenAI 兼容、Anthropic 兼容服务或本地翻译。页面默认同时显示原文与译文；滚动或异步加载的新内容会继续识别并翻译。升级扩展后保留已选择的翻译服务。

目标语言中的「中文」为简体中文，「繁中」为繁体中文；可在扩展弹窗、设置页、视频字幕设置或 PDF 阅读器中选择。可用语言取决于翻译服务，本地实验服务暂不支持繁体中文。

全文翻译包含网页中嵌入的阅读内容，包括来自其他网站的 iframe。翻译开关、恢复原文、语言和显示模式在整页统一生效；嵌入内容接近可见区域后翻译，隐藏内容显示后继续处理。

在「设置 → 通用」可以关闭「全文翻译包含嵌入内容」，或填写嵌入内容排除规则。每行一个网址规则，`*` 匹配任意字符；例如 `https://example.com/widget/*`。使用 `https://site.example/* => https://embed.example/*` 可限定只排除指定网页中的嵌入内容。修改后点击「保存」。浏览器限制访问的文档无法翻译，可在调试面板的「页面文档」中查看各文档的处理状态与排除原因。

### 自动翻译

在扩展弹窗的语言栏点击「自动」即可启停，立即生效。首次开启且尚未配置规则时，默认自动翻译非目标语言页面；已有站点和语言规则会保留。自动翻译默认关闭，沿用当前的翻译语言、服务和显示模式；使用在线服务时会消耗对应额度。

开启后，「自动」右侧显示「＋」，点击可将当前网站的域名加入自动翻译列表并立即生效。已有规则会复用，同站点的已停用规则会重新启用；加入后显示「✓」，再次点击可排除该网站，再点「＋」可重新加入，不会产生重复规则。排除优先于站点及非目标语言规则，刷新网页后仍有效，仅作用于当前域名和端口；手动翻译仍可使用。浏览器内部页面和本地文件不支持此操作。

要限定自动翻译范围，在「设置 → 自动翻译」配置规则并点击页面底部的「保存」：

- **站点列表**：预先列出 GitHub、Stack Overflow、英文维基百科、Reddit、Medium 和 Hacker News。勾选启用，地址可直接编辑；点击底部「＋」新增一行，点击行末「－」删除，预置站点同样可以删除。保存后生效，删除的预置项不会在重开设置时恢复。
- **站点匹配**：`example.com` 包含子域名，`*.example.com` 仅匹配子域名，`https://example.com/docs/*` 限定 HTTPS 和路径。
- **已排除的网站**：显示通过「✓」排除的域名。点击域名旁的「×」取消排除，并点击页面底部「保存」生效。
- **非目标语言页面**：启用自动翻译后，总开关右侧显示「页面语言不是目标语言时自动翻译」勾选项。首次启用且未配置规则时默认勾选，可取消以仅按站点列表翻译。浏览器在本机识别页面正文语言；与目标语言相同或无法可靠识别时跳过。

满足任意一项规则即可触发。网页在前台显示并加载正文后开始翻译，随后加载的新内容沿用现有的增量翻译。手动点击「显示全文」恢复原文后，当前地址不会再次自动开启；刷新或进入新地址后重新匹配规则。自动翻译只针对普通网页，不会自动打开 PDF 工作区或下载本地翻译模型。

开启全文翻译后，修改源语言或目标语言会自动从原文重新翻译当前区域，后续滚动和新加载的内容也使用新语言，无需先恢复原文。已选择显示原文的页面会保持原文，下次开始翻译时使用最新语言。

### 显示模式

在扩展弹窗的「显示模式」中选择：

已翻译的内容会立即切换显示方式，复用现有译文，不重复请求翻译服务；正在翻译和后续加载的内容也会使用新模式。

| 模式 | 显示方式 |
| --- | --- |
| 译文替换 | 隐藏原文，在原页面中显示译文 |
| 原色对照（默认） | 在原文下方显示译文，沿用原文颜色 |
| 双色对照 | 在原文下方显示译文，使用不同颜色区分，并适配明暗背景 |

开启「翻译代码注释」后，GitHub 代码视图中的注释译文与原注释同行显示，保持代码与行号对齐；较长内容可在代码区横向滚动查看。

### 外观

在「设置 → 外观」选择浅色、深色或跟随系统。浅色与深色可分别指定配色方案，内置雾青、暖纸、夜青和午夜蓝。

切换到「菜单功能」，左侧是可直接编辑的弹窗预览，右侧是可添加的功能。点击左侧按钮将其移回右侧，点击右侧按钮将其添加到菜单末尾；拖动左侧按钮可自由排序：拖到按钮旁吸附为两个半宽按钮，拖到行间则独占一行；移走同一行的按钮后，剩余按钮自动铺满整行。也可聚焦按钮后按 `Alt + 方向键` 排序。GitHub 和官网固定在底部，可选择显示或隐藏。拖动时按 `Esc` 或在预览外松开可取消。点击「保存」后应用到已打开的弹窗；「恢复默认布局」仅重置菜单。移除入口会保留功能的当前开关状态，语言、翻译服务、翻译模式和右上角设置始终显示。

点击「复制方案」创建自定义配色，展开对应分组后通过颜色块或 `#RRGGBB` 色值调整颜色，右侧同步预览：

- **界面**：设置与弹窗的背景、文字、强调色、边框及提示颜色。
- **译文与段落**：浅色网页和深色网页上的双色译文颜色，以及段落高亮色。译文按所在网页的背景选择颜色并自动调整对比度；原色对照和译文替换沿用原文颜色。
- **划词翻译**：圆点或下划线入口、词典卡片背景、文字和强调色。
- **图片翻译入口**：图片旁翻译按钮的背景与文字颜色，图片内译文仍按原图配色。

自定义方案支持重命名、重置颜色和删除；修改后点击页面底部「保存」。已打开网页中的扩展控件和双色译文会同步换色，无需重新请求翻译。

### 段落翻译

段落模式使用键盘与鼠标操作，纯触屏环境不显示此入口及操作说明。

开关在当前浏览器中全局生效，已打开、新打开和刷新的网页共用状态；任一页面关闭后，其他页面也会关闭。切换开关会保留已有译文。

1. 在扩展弹窗中点击「段落翻译」，按钮高亮表示已开启。
2. 按住 `Ctrl`（可在「快捷键 → 局部操作」中修改），点击需要翻译的段落。
3. 再次点击同一段落恢复原文；使用结束后，再点一次「段落翻译」按钮关闭。可在「翻译模式」中随时切换「译文替换」「原色对照」或「双色对照」，段落模式保持开启。

也可在扩展弹窗中开启「右键翻译」，在网页正文或空白处右键，直接选择「全文翻译」。正在翻译或已显示译文时，该入口显示为「恢复原文」，点击可停止翻译并还原页面。切换网页后，菜单名称随当前页面状态更新。语言、服务和显示模式沿用当前设置。

### 快捷键

翻译快捷键是浏览器的扩展快捷键：按下的那一刻浏览器才授权当前网页，扩展不会预先读取任何网页。在「设置 → 快捷键」可查看当前绑定，点击「在浏览器中修改快捷键」进入 `chrome://extensions/shortcuts` 调整。默认绑定如下：

| 操作 | 默认快捷键 |
| --- | --- |
| 翻译当前输入框（需要大模型服务） | `Alt+A`（macOS：`Option+A`） |
| 翻译全文 / 停止翻译并恢复原文 | `Alt+Shift+Y` |
| 段落翻译 / 恢复该段原文 | `Alt+Shift+Q` |
| 开启 / 关闭段落模式 | `Alt+Shift+L` |
| 循环切换译文替换、原色对照、双色对照 | 未设置，可自行绑定 |

浏览器最多为扩展预设 4 个默认快捷键，因此「切换译文显示模式」需要自行绑定。全文翻译中再次按下快捷键会停止并恢复原文，重新开启时复用已完成的译文；切换显示模式会退出段落模式并立即更新已有译文，不重复请求翻译。

使用段落翻译快捷键时，将鼠标移到正文段落，或选中段落中的文字，即可原位翻译完整段落；选区跨越多个段落时逐段处理，再次按下恢复对应段落的原文。此快捷键不依赖「段落模式」「右键翻译」或「划词翻译」开关，语言、服务和显示方式沿用当前设置。

### 翻译输入框

在任意输入框、文本域或富文本编辑器中按 `Option+A`（Windows / Linux：`Alt+A`），把框内文字翻译成「设置 → 通用 → 输入框翻译写入语言」（默认英文）并写回原处；有选区时只翻译选中部分，输入框里已经是该语言时改译为目标语言。写回走浏览器的撤销栈，`Ctrl/⌘+Z` 可还原。

输入框翻译只使用你配置的 OpenAI 兼容或 Anthropic 兼容服务，每次一次请求，文字不写入翻译缓存。尚未配置时，页面会提示先去设置。当前不支持嵌在跨域 iframe 内的输入框。

### 权限

安装时扩展不申请任何网站访问权限，只在你操作时授权：

- 点击工具栏图标、按下快捷键或使用右键菜单时，浏览器只对当前标签页授权，扩展随后在该页面运行；刷新同源页面后会自动恢复，跨站跳转后需要重新操作。
- 翻译服务的访问（Google 的接口，或你填写的 OpenAI / Anthropic 兼容地址）在你第一次点击翻译、或在设置页保存时由浏览器弹窗确认。
- 自动翻译、视频字幕站点、图片翻译、划词词典、模型下载和 PDF 来源，分别在你开启或点击对应功能时请求所需的站点，可在浏览器的扩展详情中随时撤销。
- 不在已授权范围内的跨域 iframe 不会被翻译。

划词卡片仍通过选区旁的入口打开。默认用 `Ctrl+Enter`（macOS：`Command+Enter`）提交编辑后的原文，`Esc` 关闭卡片；可在「局部操作」中修改。页面翻译快捷键不会在卡片编辑区、输入框或其他可编辑区域内触发。

「局部操作」可在设置页自定义，每项右侧有独立开关，关闭后保留原按键：段落点击可选 Ctrl、Alt、Shift、Command/Win 及其组合；提交划词原文、关闭划词卡片可录入组合键或功能键，点击按键框后按下新的组合，`Esc` 取消，`Backspace` 或 `Delete` 清空，需要绑定 Esc 时点击旁边的「使用 Esc」。也可点击每项旁的「默认」，或点击顶部「恢复默认」。

## 划词翻译

选中网页中的文字后，点击选区旁的小圆点打开结果卡片。在扩展弹窗中点击「划词翻译」可启停该功能；在「更多设置 → 划词翻译」中可调整入口样式和默认词典。

- 支持有道词典和 Bing 词典，无需填写 API Key。卡片内也可临时切换词典。
- 单个字母单词先查词典，允许词内的连字符和撇号；显示词条提供的英美音标、发音和词性释义，点击发音按钮播放，不自动朗读。单词没有释义时，自动使用当前翻译服务。
- 多个单词、句子、段落及中日韩文字直接使用当前翻译服务，沿用设置中的源语言、目标语言和缓存偏好。翻译模式显示实际服务名称及译文，不显示词典音标；Firefox 本地翻译缺少模型时提示安装，不切换其他在线翻译服务。
- 卡片顶部的原文可直接编辑，修改后点击「查词」或「翻译」，也可按 `Ctrl+Enter` 提交；`Enter` 保留换行。编辑过程中不联网，不修改网页原文，提交后按单词或文本重新处理。
- 点击页面其他位置、按 `Esc`、滚动页面或改变窗口大小会关闭卡片。卡片内的释义可正常选择和复制。
- 支持不超过 5,000 个字符的选区，词典查询限 100 个字符；输入框、可编辑区域和浏览器内置页面暂不支持；嵌入页面中的浮层显示范围受嵌入区域尺寸限制。

选中文字时仅显示入口，点击后才查词或翻译，不附带整页内容。词典结果不保存；译文按现有缓存设置处理。两个词典使用各自的网页服务，访问限制或服务调整可能导致查询、发音暂时不可用；请求失败时可重试，词典请求失败不会当作“未收录”自动转入翻译。

## 图片翻译

### 安装识别模型

1. 在弹窗或设置中，点击「图片翻译」旁的扳手图标。
2. 等待约 20.5 MB 的文字识别（OCR）模型下载、校验和安装完成。
3. 开启「图片翻译」。

安装在后台进行，关闭弹窗不会中断。将鼠标移到「？」上可查看下载进度和安装状态；安装失败时，点击扳手重试。

### 翻译与切换

1. 将鼠标移到网页图片上，点击「译」；也可右键点击图片，选择「使用 WuPage 翻译图片」。
2. 识别完成后，译文覆盖在原图的文字区域。
3. 点击「原」查看原图，点击「译」恢复译图。

文字识别在本地完成，翻译服务仅接收识别出的文字。原始图片文件和链接保持不变。

### 支持范围

- 识别语言：简体中文、繁体中文、英文和日文。
- 图片类型：网页中的静态图片；动画、CSS 背景图及嵌入框架内部图片暂不保证支持。
- 文件大小：下载上限为 12 MB，超大图片会缩放后识别。
- 访问条件：图片地址须可访问；鉴权、防盗链或特殊地址可能导致读取失败。
- 显示效果：纯色背景较适合覆盖译文；复杂纹理、艺术字、竖排、低对比度和密集小字可能出现识别或定位偏差。

### 模型与缓存

关闭「图片翻译」会移除译文覆盖层，保留本地模型。点击旁边的垃圾桶可删除模型并关闭该功能。

开启缓存后，仅保存识别出的文字区域和译文，不保存原始图片。「清除缓存」删除翻译结果，不删除 OCR 模型。

<details>
<summary>图片文字的识别与显示说明</summary>

译文按识别位置覆盖，纯数字、百分比、倍率和常见数量缩写保持原样。覆盖区域使用从图片中采样的背景色，透明图片保留透明度与原文字颜色；复杂背景不进行无痕修复。

图片译文按实际显示尺寸与屏幕像素密度绘制。放大图片或改变窗口大小时，会复用已有译文重绘，避免将低分辨率译图直接拉伸；SVG 原图按所需尺寸重新绘制。普通位图的细节仍受原始分辨率限制。

宽幅透明文字图中，同一行的相邻片段会合并翻译，并尝试补全覆盖范围内遗漏的标点。识别失败、无可翻译内容或译文未变化时，页面会显示相应提示；空结果不写入缓存。

全文翻译还会读取网页图片提供的长段替代文字（`alt`），无需 OCR。能够识别段落间隔的透明文字图片，可按段显示原图文字与对应译文；「译文替换」模式仅显示译文。其他图片保留原图，在下方显示翻译后的说明，文字颜色随网页显示。恢复原文时还原原图。

</details>

## PDF 翻译

### 效果预览

英文 → 简体中文，左侧为原文，右侧为译文。

![PDF 课件翻译：左侧英文原文，右侧简体中文译文](docs/example/PDF-ppt-trans.png)

### 打开文档

1. 在浏览器中打开 PDF。
2. 点击 WuPage 弹窗中的「翻译PDF」，进入双栏工作区并开始翻译。
3. 在工作区中，可通过选择文件、拖放文件或粘贴 PDF 地址打开其他文档；打开后自动使用顶部选定的服务开始翻译。

也可随时点击弹窗中的「打开 PDF」，进入空白工作区后选择或拖入文件。本地 PDF 未开启文件网址访问权限时，浏览器可能不向扩展提供当前地址，导致「翻译全文」不可用；此时仍可通过「打开 PDF」选择文件，或在扩展详情中开启「允许访问文件网址」后重新打开弹窗。

弹窗无法读取当前地址时会提供「打开扩展设置」按钮，点击可进入 WuPage 的扩展详情页。开启「允许访问文件网址」或「允许访问文件 URL」后，回到 PDF 并重新打开弹窗。

打开文档后，默认翻译当前页及前后各 5 页，最多 11 页。范围内完成后等待继续阅读；滚动到新位置会自动补译附近未完成的页面。快速跳页时，尚未开始的旧范围任务会被移出队列；已完成的同语言、同服务译文及手动编辑会保留。

在扩展设置的「性能设置 → PDF 翻译范围」中调整前后页数：0 表示只翻译当前页，选择「无限制（整份 PDF）」可翻译全文。保存后，下一次打开文档或点击翻译时生效。

### 校对与导出

工作区按页对齐显示原文与译文。译文块支持直接编辑、移动、缩放和删除。点击「下载译文」会先补全整份 PDF 的翻译，再生成译文文件，不受阅读翻译范围限制。同语言、同服务下已完成的译文和手动校对会保留，无须重复翻译。若有页面翻译失败，下载会暂停并提示重试；再次点击「下载译文」可补译失败页。

论文中的参考文献条目默认保留原文，包括作者、标题、期刊、年份、页码和网址；「References」等章节标题正常翻译。正文引用标号、公式变量、文内已定义的缩写和图编号会受到保护。识别出的论文主题、邻近正文和缩写定义会随待译文字提供给当前翻译服务，帮助保持术语一致。

首次点击「下载译文」时，可选择「安装并导出」或「直接导出」。完整字体包约 16.4 MB，仅在确认安装后从 Noto 官方仓库下载；安装后，译文可搜索、复制，放大更清晰，并尽可能保留原有矢量图形。选择直接导出时，无须下载字体，生成与预览一致的图像版 PDF，文字无法选中或搜索。本次工作区内再次导出不会重复提醒；之后可点击下载按钮旁的扳手安装，安装后该按钮变为垃圾桶，可删除字体包。字体按大小与 SHA-256 校验后缓存在本机，后续可离线使用，清除翻译缓存不会删除字体。

安装字体后，参考文献整页无需翻译时直接保留原页；部分保留的原文字形和公式沿用原图外观。含特殊绘图或可选图层的页面使用匹配预览的页面图像并附加文字层。遇到无法容纳的译文会提示调整译文块后再下载。

带点线的目录按条目翻译，保留缩进、点线和原始页码。

### 公式保留

独立公式与编号保留原位；行内公式随译文排版，保留上下标、分式和符号形状。显示和导出均使用原公式图像。

公式识别依赖 PDF 文本层，复杂文档可能存在识别偏差。

<details>
<summary>本地文件访问权限</summary>

直接读取浏览器中已打开的本地 PDF，需要在扩展详情中开启「允许访问文件网址」或「允许访问文件 URL」。在工作区选择或拖放文件，不需要此权限。

开启权限后，点击工作区中的「重试打开」。如果浏览器重载扩展并关闭了工作区，返回原 PDF 标签页，再次点击「翻译PDF」。

</details>

### 使用限制

- PDF 须包含可提取的文字，当前不支持纯图片或扫描版文档。
- 复杂表格、特殊字体和高度图形化的版面可能需要手动校正。
- 直接导出的图像版 PDF 不支持文字选择或搜索；安装完整字体后可导出文字层，部分复杂页面仍使用页面图像保留外观。

## 翻译服务

WuPage 提供四类翻译服务，在「设置 → 翻译服务」的下拉框中选择当前服务：

| 服务 | 所需配置 |
| --- | --- |
| Google 翻译 | 无需密钥，使用 Google 翻译网页接口，新安装默认使用 |
| OpenAI 兼容 | 服务地址（Base URL）、模型及服务要求的 API Key；适用于 OpenAI、兼容 `/chat/completions` 的网关和本地服务 |
| Anthropic 兼容 | 服务地址、模型及所需的 API Key；使用 Anthropic Messages 接口 |
| Firefox 本地翻译（实验） | 预先下载或导入语言模型，无需密钥，准备完成后可离线使用 |

Google 翻译使用网页翻译接口，可能受到限流、地区限制或接口变更影响；不可用时可切换到已配置的 LLM 服务或本地翻译。第三方服务的可用性、用量限制和费用以服务商为准。免费服务限流或失败时，扩展不会自动转发给其他服务。

设置页可选中已停用的服务，编辑、保存或手动测试其配置；选中与测试不会自动启用该服务，也不会切换实际翻译所用的服务。通过「启用此服务」开关停用服务后，配置表单继续保留；弹窗和 PDF 的翻译服务列表仅显示已启用项。设置页右侧的「＋」可添加自定义的 OpenAI 兼容或 Anthropic 兼容服务，自定义服务可用「删除」按钮移除。

升级时，旧版本保存的 Microsoft、腾讯、Yandex、火山、MyMemory、豆包、HTTP 模板及 Azure / Google Cloud API 配置会被移除；已填写 API Key 的 DeepSeek 与 Zhipu GLM 配置会转为 OpenAI 兼容服务并保留地址、密钥、模型和提示词。当前使用的服务已不存在时，自动回到 Google 翻译。

### LLM 服务

在「常规」中填写 Base URL、API Key、模型和系统提示词，点击「测试服务」会先保存设置再验证连接。API Key 可留空，用于无需认证的本地服务。

「性能设置」集中调整通用分块与并发参数、当前服务是否继承通用参数，以及 PDF 翻译范围。切换翻译服务时，当前服务的性能设置随之切换。

OpenAI 兼容服务使用 Chat Completions 格式，Base URL 可填写 `https://api.openai.com/v1`、本地服务的 `http://127.0.0.1:端口/v1` 或完整的 `/chat/completions` 地址。Anthropic 兼容服务使用 Messages 格式，只填写主机（如 `https://api.anthropic.com`）时自动补全 `/v1/messages`。

LLM 返回值应为与输入顺序一致的 JSON 字符串数组。只有一个输入项时，也兼容单个字符串结果。

### Firefox 本地翻译（实验）

使用 Firefox 翻译所采用的 Bergamot 引擎与 Mozilla 语言模型，在浏览器内执行翻译，无需额外的本地服务；Chrome / Edge 用户无需安装 Firefox。

1. 打开扩展设置，在「翻译服务」中选择「Firefox 本地翻译（实验）」。
2. 阅读下载大小、磁盘空间、CPU、内存和耗电说明。
3. 选择需要的语言方向，点击「下载模型」。选择服务或开始翻译不会自动下载模型。
4. 等待显示「模型已就绪」，再开始网页、文本层 PDF 或已安装 OCR 的图片翻译。

支持英语、简体中文、日语、德语、法语、西班牙语和俄语。模型按方向单独安装，每个约 35–55 MB，具体大小以设置页为准。非英语之间的翻译经英语中转，例如日语 → 简体中文需要分别准备「日语 → 英语」和「英语 → 简体中文」。自动检测使用浏览器的本地语言识别；短文本识别不准时，手动选择源语言。

下载遇到中断时会自动重试，已完成的文件和每 1 MB 的下载进度保存在本机。可点击「暂停下载」，稍后点击「继续下载」；服务器不支持续传时，当前文件会重新下载。关闭设置页后下载继续，退出浏览器或重载扩展后需重新点击继续。

若模型服务器无法连接，展开「网络不畅或离线安装」，在网络较好的设备上保存列出的全部文件，复制到本机，再点击「离线导入」。文件按大小与 SHA-256 校验，可分次导入，也可保留 CDN 自动生成的文件名。

模型就绪后，翻译不依赖网络，文本不会发送至在线服务。运行时使用本机 CPU 和一个工作线程，可能增加发热、耗电，内存可能达到数百 MB；空闲 60 秒后释放运行内存，模型文件继续保留。点击「删除模型」移除所选方向的数据；清除翻译缓存不会删除模型。

这是实验功能，复杂内容的译文质量和速度需结合设备评估。暂不支持韩语和繁体中文；缺少模型或语言不支持时，按提示补齐模型或手动切换服务。需要支持 WebAssembly SIMD 的浏览器和设备。

## 故障排查

| 现象 | 处理方法 |
| --- | --- |
| 设置页语言和服务列表为空、按钮无响应 | 在扩展管理页重新加载 WuPage 后，关闭并重开设置页；仍失败时记录浏览器名称、内核版本、WuPage 版本及扩展卡片中的错误信息 |
| 点击全文翻译无响应 | 确认当前为普通网页；浏览器设置页和扩展内部页面不支持全文翻译。安装或更新后，刷新页面重试 |
| 翻译请求失败 | 检查网络、服务地址、密钥和用量限制；页面上的提示会给出失败原因。首次使用需在浏览器弹窗中允许访问对应服务 |
| 默认翻译服务不可用 | 检查网络，或切换到已配置的其他翻译服务 |
| 本地 Ollama 服务返回 403 | 在服务端设置 `OLLAMA_ORIGINS` 允许扩展来源（如 `chrome-extension://扩展ID`），完全退出并重启 Ollama |
| 本地翻译提示缺少模型 | 在设置中下载或离线导入对应方向的全部文件；经英语中转时需准备两个方向 |
| 本地模型下载失败 | 点击继续下载，或使用「网络不畅或离线安装」中的文件链接与离线导入 |
| 图片翻译开关不可用 | 等待 OCR 模型安装完成；安装失败时点击扳手重试 |
| 本地 PDF 无法打开 | 开启文件访问权限后重试，或在工作区中选择、拖放文件 |

## 隐私说明

在线翻译请求由扩展直接发送至所选服务商；选择 Firefox 本地翻译时，对应翻译任务的文本在本机处理。划词查词独立使用选中的有道或 Bing 在线词典，仅在点击入口后发送选中文字。WuPage 不提供翻译代理或分析服务；API 凭据、扩展设置和可选翻译缓存保存在浏览器本地。

网页、PDF 及图片中识别出的待翻译文字会交由所选服务商处理。翻译敏感内容前，应确认相应服务商的隐私条款。完整说明见 [隐私政策](PRIVACY.md)。
